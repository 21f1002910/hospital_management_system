# hospital_management_system
A full-stack Hospital Management System that enables Admins, Doctors, and Patients to manage appointments, treatments, and records efficiently — replacing manual registers with a secure, scalable web app.
Tech Stack

# Layer                Technology
Backend              Flask, Flask-RESTful, Flask-JWT-Extended, SQLAlchemy, Flask-Migrate
Frontend             Vue 3 (Vite), Pinia, Vue Router, Bootstrap 5
Database             SQLite (programmatic creation)
Caching              RedisAsync JobsCelery + Redis
Styling              Bootstrap 5 (no other CSS framework)
Validation           HTML5 + Backend (Flask-WTF)
